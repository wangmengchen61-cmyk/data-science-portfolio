# Mengchen Wang — Data Science Portfolio

This repository powers my GitHub Pages portfolio website.

- **Website:** https://<your-username>.github.io/data-science-portfolio/
- **Entry file:** `index.md` (GitHub Pages serves this as the site homepage)
- **Content:** about me, technical skills, and my data science project showcase

## How this site is published

1. This repository is **public**.
2. GitHub Pages is enabled in **Settings → Pages** with:
   - Source: **Deploy from a branch**
   - Branch: `main`, folder `/ (root)`
3. `index.md` at the repository root is rendered as the homepage.
